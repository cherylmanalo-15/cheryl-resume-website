# Cheryl Manalo Resume Website

A single-page React/Vite resume website.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy with GitHub Pages

1. Create a new public GitHub repo, for example: `cheryl-resume-website`
2. Upload these project files to the repo.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Add the workflow below at `.github/workflows/deploy.yml`.
6. Push to `main`.

Your site will publish at:

`https://YOUR-GITHUB-USERNAME.github.io/cheryl-resume-website/`
